MARKAZIY OSIYO OB-HAVO — iPhone uchun PWA
===========================================

Bu versiya Mac yoki Apple Developer Program talab qilmaydi.

iPhone'da dastur kabi ishlaydi:
- Safari orqali ochiladi
- Home Screen'ga o'rnatiladi
- alohida ikonka bo'ladi
- fullscreen/standalone rejimda ishlaydi
- offline kesh bor
- har 15 daqiqada ma'lumotni yangilashga urinadi

SHAHARLAR:
Toshkent, Olmaota, Bishkek, Dushanbe, Ashxobod

TILLAR:
O'zbekcha, Русский, Қазақша, Кыргызча, Тоҷикӣ, Türkmençe

GITHUB ORQALI JOYLASH:
1. ZIP ichidagi BARCHA fayllarni yangi GitHub repository'ga yuklang.
2. Actions bo'limida "Deploy PWA to GitHub Pages" ishga tushadi.
3. Repository → Settings → Pages bo'limida Source sifatida "GitHub Actions" tanlanganini tekshiring.
4. Actions tugagach, Pages manzili paydo bo'ladi.
5. Shu manzilni iPhone Safari'da oching.
6. Share tugmasi → Add to Home Screen.
7. "Add" bosing.

Shundan keyin dastur iPhone bosh ekranida oddiy ilovadek ko'rinadi.

MUHIM:
Bu native .ipa emas, balki PWA. Bepul Apple ID va Mac bo'lmaganda bu eng qulay va qonuniy usul.
